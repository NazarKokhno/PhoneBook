# Phone Book

A console-based phone book application written in C++.

## Features

- Add new contacts
- Delete contacts by full name
- Search contacts by full name
- Display all contacts
- Save contacts to a text file
- Load contacts from a text file

## Contact Information

Each contact contains:
- Full name
- Home phone
- Mobile phone
- Work phone
- Additional information

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Dynamic memory allocation
- File handling

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio.
3. Build and run the application.
4. Use the console menu to manage contacts.

## Data Storage

Contacts are stored in `contactsData.txt`.

The file uses the following format:

`Full Name|House Phone|Mobile Phone|Work Phone|Additional Info`

## Purpose

This project was created to practice C++, OOP, dynamic memory management, and file operations.
